# Lantern Labyrinth

랜턴 불빛에 의지해 미로를 빠져나가는 브라우저 게임. 의존성 없는 단일 HTML 파일입니다.

**플레이:** `index.html`을 브라우저로 열면 됩니다. (GitHub Pages를 켜면 바로 웹에서 플레이 가능)

## 플레이 방법

좌상단에서 출발해 우하단의 초록색 문(Gate)에 도달하면 클리어.

| 조작 | |
|---|---|
| 이동 | 방향키 / `W` `A` `S` `D` / 화면 D-패드 / 보드 위 스와이프 |
| Lantern | 시야를 주변으로 제한하는 랜턴 모드 on/off |
| Hint | 현재 위치에서 출구까지의 경로를 2.6초간 표시 (단계당 3회) |
| New maze | 같은 깊이에서 새 미로 생성 |

## 구현

- **미로 생성** — 반복형 recursive backtracker. 순환이 없는 perfect maze라 정답 경로가 항상 정확히 하나 존재합니다. 셀마다 4방향 벽을 비트마스크(`N|E|S|W`)로 저장.
- **par** — BFS로 구한 출발점→출구 최단 걸음 수. 내 걸음 수와 나란히 표시되고, par로 클리어하면 별도 메시지가 뜹니다.
- **Hint** — 현재 위치에서 출구까지 같은 BFS를 다시 돌려 점선 경로를 그립니다.
- **난이도** — 깊이 1~12, 9×9에서 31×31까지 2칸씩 확장.
- **기록** — 깊이별 최고 기록은 `localStorage`에 저장 (브라우저 로컬 전용).
- **렌더링** — Canvas 2D, `devicePixelRatio` 대응. 랜턴은 플레이어 중심 radial gradient로 주변을 덮는 방식.
